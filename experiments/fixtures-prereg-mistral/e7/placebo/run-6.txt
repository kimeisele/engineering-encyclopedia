Here's a Python implementation of a thread-safe shared counter using a lock to prevent lost updates:

```python
import threading

class SharedCounter:
    def __init__(self, initial_value=0):
        self._value = initial_value
        self._lock = threading.Lock()

    def increment(self, amount=1):
        with self._lock:
            self._value += amount
            return self._value

    def get_value(self):
        with self._lock:
            return self._value
```
