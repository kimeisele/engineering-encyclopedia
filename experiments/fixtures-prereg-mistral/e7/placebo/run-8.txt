Here's a Python implementation of a thread-safe shared counter using a lock to prevent lost updates:

```python
import threading

class SharedCounter:
    def __init__(self, initial_value=0):
        self.value = initial_value
        self.lock = threading.Lock()

    def increment(self, amount=1):
        with self.lock:
            self.value += amount
            return self.value

    def get_value(self):
        with self.lock:
            return self.value
```
