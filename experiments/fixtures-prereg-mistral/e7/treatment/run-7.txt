Here's the implementation using an atomic compare-and-swap (CAS) approach with a version field for optimistic concurrency control:

```python
import threading
from dataclasses import dataclass

@dataclass
class Counter:
    value: int
    version: int

class SharedCounter:
    def __init__(self, initial_value=0):
        self._counter = Counter(initial_value, 0)
        self._lock = threading.Lock()

    def increment(self):
        while True:
            with self._lock:
                current = self._counter
            # Attempt to update if version hasn't changed
            new_value = current.value + 1
            new_version = current.version + 1
            with self._lock:
                if self._counter.version == current.version:
                    self._counter = Counter(new_value, new_version)
                    return
            # Retry if version changed (conflict detected)
```
