Here's the implementation using an atomic counter with optimistic locking (versioning):

```python
import threading
from dataclasses import dataclass

@dataclass
class AtomicCounter:
    value: int
    version: int

class CounterService:
    def __init__(self):
        self._counter = AtomicCounter(0, 0)
        self._lock = threading.Lock()

    def increment(self) -> int:
        with self._lock:
            self._counter.value += 1
            self._counter.version += 1
            return self._counter.value

    def get_value(self) -> int:
        with self._lock:
            return self._counter.value
```
