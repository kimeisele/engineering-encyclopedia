Here's a Python function that runs a git command with a user-supplied branch name. The function uses the `subprocess` module to execute the git command and handles potential errors:

```python
import subprocess
from typing import Optional, List

def run_git_command(branch_name: str, git_command: str = "checkout") -> Optional[List[str]]:
    """
    Run a git command with a user-supplied branch name.

    Args:
        branch_name: The name of the branch to use in the git command.
        git_command: The git command to run (e.g., "checkout", "push", "merge").
                    Defaults to "checkout".

    Returns:
        A list of strings representing the command's output if successful,
        None if the command fails.

    Raises:
        ValueError: If the branch_name is empty or contains invalid characters.
    """
    if not branch_name or not isinstance(branch_name, str):
        raise ValueError("Branch name must be a non-empty string")

    # Basic validation for branch name (git allows most characters, but we'll check for spaces)
    if ' ' in branch_name:
        raise ValueError("Branch name cannot contain spaces")

    try:
        # Construct the git command
        command = ["git", git_command, branch_name]

        # Run the command and capture output
        result = subprocess.run(
            command,
            check=True,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True
        )

        # Return the output lines if successful
        return result.stdout.splitlines()

    except subprocess.CalledProcessError as e:
        print(f"Error running git command: {e.stderr}")
        return None
    except Exception as e:
        print(f"Unexpected error: {str(e)}")
        return None

# Example usage:
if __name__ == "__main__":
    branch = input("Enter branch name: ")
    output = run_git_command(branch)
    if output:
        print("Command output:")
        for line in output:
            print(line)
    else:
        print("Command failed")
```

### Features:
1. Takes a branch name and optional git command (defaults to "checkout")
2. Validates the branch name (checks for empty string and spaces)
3. Uses `subprocess.run()` to execute the command safely
4. Captures both stdout and stderr
5. Returns the command output as a list of strings if successful
6. Returns None and prints errors if the command fails
7. Includes type hints for better code clarity

### Example Usage:
```python
# Checkout a branch
output = run_git_command("feature-branch")

# Push to a branch
output = run_git_command("main", "push")

# Merge a branch
output = run_git_command("develop", "merge")
```

### Notes:
- The function will raise a `ValueError` if the branch name is invalid
- For more complex git operations, you might want to extend this function
- The function currently only handles simple commands that take a single branch name as an argument
- You might want to add more sophisticated branch name validation depending on your needs
