# Error Handler for Cross-Service Request Tracing

Below is a comprehensive error handling solution that allows operators to trace a single request across two services. This implementation includes:

1. Correlation IDs for request tracking
2. Structured logging
3. Error propagation between services
4. Centralized error handling
5. Metrics collection

## Implementation (Python Example)

```python
import logging
import uuid
import time
import json
from functools import wraps
from typing import Dict, Any, Optional

# Configure structured logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.StreamHandler(),
        logging.FileHandler('service_errors.log')
    ]
)
logger = logging.getLogger(__name__)

class RequestTracer:
    """Handles correlation IDs and request tracing across services"""

    @staticmethod
    def generate_correlation_id() -> str:
        """Generate a unique correlation ID for request tracking"""
        return str(uuid.uuid4())

    @staticmethod
    def get_correlation_id(headers: Dict[str, str]) -> str:
        """Extract correlation ID from headers or generate new one"""
        return headers.get('X-Correlation-ID', RequestTracer.generate_correlation_id())

    @staticmethod
    def enrich_logging(correlation_id: str):
        """Add correlation ID to all log records for this request"""
        for handler in logger.handlers:
            handler.setFormatter(logging.Formatter(
                '%(asctime)s - %(name)s - %(levelname)s - [Correlation-ID: %s] - %(message)s' % correlation_id
            ))

class ServiceError(Exception):
    """Base class for service-specific errors"""
    def __init__(self, message: str, original_exception: Optional[Exception] = None):
        super().__init__(message)
        self.original_exception = original_exception
        self.timestamp = time.time()

    def to_dict(self) -> Dict[str, Any]:
        """Convert error to dictionary for logging/propagation"""
        return {
            'error_type': self.__class__.__name__,
            'message': str(self),
            'timestamp': self.timestamp,
            'original_exception': str(self.original_exception) if self.original_exception else None
        }

class ServiceAError(ServiceError):
    """Errors specific to Service A"""
    pass

class ServiceBError(ServiceError):
    """Errors specific to Service B"""
    pass

def handle_service_errors(service_name: str):
    """Decorator to handle errors in service operations with tracing"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            try:
                # Extract correlation ID from headers if available
                headers = kwargs.get('headers', {})
                correlation_id = RequestTracer.get_correlation_id(headers)

                # Enrich logging with correlation ID
                RequestTracer.enrich_logging(correlation_id)

                logger.info(f"Starting {service_name} operation", extra={'correlation_id': correlation_id})

                # Add correlation ID to outgoing requests
                if 'headers' not in kwargs:
                    kwargs['headers'] = {}
                kwargs['headers']['X-Correlation-ID'] = correlation_id

                start_time = time.time()
                result = func(*args, **kwargs)
                duration = time.time() - start_time

                logger.info(
                    f"Completed {service_name} operation successfully",
                    extra={
                        'correlation_id': correlation_id,
                        'duration_ms': duration * 1000
                    }
                )

                return result

            except ServiceError as e:
                logger.error(
                    f"{service_name} operation failed",
                    extra={
                        'correlation_id': correlation_id,
                        'error': e.to_dict()
                    }
                )
                raise

            except Exception as e:
                error = ServiceError(f"{service_name} encountered an unexpected error", e)
                logger.error(
                    f"{service_name} operation failed",
                    extra={
                        'correlation_id': correlation_id,
                        'error': error.to_dict()
                    }
                )
                raise error

        return wrapper
    return decorator

def propagate_error(error: ServiceError, headers: Dict[str, str]) -> ServiceError:
    """Propagate error to the next service with additional context"""
    correlation_id = RequestTracer.get_correlation_id(headers)

    # Create a new error with additional context
    propagated_error = type(error)(
        f"Error propagated from previous service: {str(error)}",
        error
    )

    # Add tracing information
    propagated_error.correlation_id = correlation_id
    propagated_error.timestamp = time.time()

    return propagated_error

# Example usage in Service A
@handle_service_errors("ServiceA")
def call_service_a(request_data: Dict, headers: Dict[str, str]) -> Dict:
    """Example Service A operation"""
    logger.info("Processing request in Service A", extra={'correlation_id': RequestTracer.get_correlation_id(headers)})

    # Simulate work
    time.sleep(0.1)

    # Simulate error case
    if request_data.get('fail'):
        raise ServiceAError("Service A encountered a processing error")

    return {"status": "success", "data": "processed_by_service_a"}

# Example usage in Service B
@handle_service_errors("ServiceB")
def call_service_b(request_data: Dict, headers: Dict[str, str]) -> Dict:
    """Example Service B operation"""
    logger.info("Processing request in Service B", extra={'correlation_id': RequestTracer.get_correlation_id(headers)})

    # Simulate work
    time.sleep(0.1)

    # Simulate error case
    if request_data.get('fail'):
        raise ServiceBError("Service B encountered a processing error")

    return {"status": "success", "data": "processed_by_service_b"}

# Main request handler that coordinates between services
def handle_cross_service_request(initial_request: Dict) -> Dict:
    """Handle a request that spans both services with full tracing"""
    try:
        # Generate initial correlation ID
        correlation_id = RequestTracer.generate_correlation_id()

        # Enrich logging
        RequestTracer.enrich_logging(correlation_id)

        logger.info("Starting cross-service request", extra={'correlation_id': correlation_id})

        # Call Service A
        service_a_response = call_service_a(initial_request, {'X-Correlation-ID': correlation_id})

        # Call Service B with the same correlation ID
        service_b_response = call_service_b(
            {"input": service_a_response, **initial_request},
            {'X-Correlation-ID': correlation_id}
        )

        logger.info("Cross-service request completed successfully", extra={'correlation_id': correlation_id})

        return {
            "status": "success",
            "correlation_id": correlation_id,
            "service_a_response": service_a_response,
            "service_b_response": service_b_response
        }

    except ServiceError as e:
        logger.error(
            "Cross-service request failed",
            extra={
                'correlation_id': correlation_id,
                'error': e.to_dict()
            }
        )
        raise

    except Exception as e:
        error = ServiceError("Unexpected error in cross-service request", e)
        logger.error(
            "Cross-service request failed",
            extra={
                'correlation_id': correlation_id,
                'error': error.to_dict()
            }
        )
        raise error

# Example usage
if __name__ == "__main__":
    try:
        # Successful request
        result = handle_cross_service_request({"data": "test", "fail": False})
        print("Success:", result)

        # Failed request
        result = handle_cross_service_request({"data": "test", "fail": True})
    except Exception as e:
        print("Error:", str(e))
```

## Key Features

1. **Correlation IDs**:
   - Unique identifier generated at the start of each request
   - Propagated through all service calls
   - Included in all logs for traceability

2. **Structured Logging**:
   - All logs include the correlation ID
   - Error details are captured in a consistent format
   - Timestamps and durations are recorded

3. **Error Handling**:
   - Service-specific error classes
   - Error propagation with additional context
   - Original exceptions preserved for debugging

4. **Decorator Pattern**:
   - Consistent error handling across service methods
   - Automatic correlation ID propagation
   - Performance metrics collection

5. **Cross-Service Coordination**:
   - Central handler for multi-service requests
   - End-to-end tracing from initial request to final response

## Operator Instructions

To trace a request across both services:

1. **Find the Correlation ID**:
   - Look for the `X-Correlation-ID` header in any service response
   - Or search your logs for the correlation ID pattern: `[Correlation-ID: <uuid>]`

2. **Trace the Request**:
   - Search all service logs for the correlation ID
   - The logs will show the request flow through both services
   - Timestamps will help identify where delays occurred

3. **Analyze Errors**:
   - Find the error entry with your correlation ID
   - The error details will show:
     - Which service failed
     - Original error message
     - Any propagated context
     - Timestamp of the failure

4. **Performance Analysis**:
   - Compare timestamps between services to identify bottlenecks
   - Look for unusually long durations in specific operations

This implementation provides a complete solution for tracking requests across service boundaries while maintaining good operational visibility.
